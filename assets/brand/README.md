# Noviqa logo assets

The user approved polishing and website-testing Current and Converge on 11 November 2026, then **selected Converge**. The exact refined Converge lockup and symbol are applied to the main website and richer alternate. Current remains a reference alternative in the separate comparison page only. Neither a production vector master nor trademark clearance is implied.

All four PNGs were generated with Image Gen using the selected concept images as direct visual references. These are original concept-generation outputs, not copied competitor assets and not finished vector artwork. No exclusivity, trademark availability or legal clearance is claimed.

- `current-lockup.png`: refined three-band symbol and lowercase wordmark, 2172 × 724 RGBA. Generation `exec-8f73ab06-7c11-4a17-9a78-645ae780b29b.png`, from selected Current board `exec-e56a7a18-a97b-45c7-aecd-985393651985.png`.
- `converge-lockup.png`: refined four-way mirrored symbol and lowercase wordmark, 2172 × 724 RGBA. Generation `exec-028a825e-e923-4f0e-b9b7-2735ef8f638b.png`, from selected Converge board `exec-f503d347-1962-40f8-b1e7-93b90325ccb2.png`.
- `current-symbol.png`: standalone icon derived by Image Gen from the refined lockup, 1254 × 1254 RGBA. Generation `exec-fd4cc127-a825-48f9-8efd-22686ea2787b.png`.
- `converge-symbol.png`: standalone icon derived by Image Gen from the refined lockup, 1254 × 1254 RGBA. Generation `exec-7dc4764e-0587-40fb-be52-e4ee5262d295.png`.

Files retain the original transparency and pixels. `brand-preview/script.js` display-crops transparent padding using alpha-bound measurements recorded in the builder. It does not draw replacement symbols or recreate the wordmark as text. Reversed samples use a CSS filter on the same artwork. Original transparent symbol canvases are used for the browser icon and actual 16/24/32/48px image-size studies, including their safe margins.

The solid site tokens remain forest `#172b23`, paper `#f5f6f0` and lime `#c4f270`. Generated raster pigments have slight tonal variation; final vector masters should use exact agreed brand colours, unify icon/lockup geometry and receive optical small-size tuning. The raster wordmarks are not an identified/licensed editable font family; select and license an editable typeface or commission custom outlines before establishing a production brand system.
